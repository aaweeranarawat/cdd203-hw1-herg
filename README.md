## Decision threshold

We classify a molecule as a hERG blocker when the model's probability is at least **0.45**. We chose it on the validation set, never the test set, by comparing three candidate rules: the lowest threshold reaching sensitivity ≥ 0.90 (0.41), Youden's J (0.50), and maximum sensitivity with specificity above 0.7 (0.37). The errors are asymmetric: a false negative lets a cardiotoxic compound advance through development at great cost and possible harm to patients, while a false positive only triggers a cheap confirmatory hERG assay. So we accept more false positives and set the threshold below 0.5. Going lower than 0.45 cost accuracy and precision quickly (in scaffold-grouped cross-validation, 0.40 dropped precision to 0.70 and specificity to 0.58), so 0.45 balances the two: on validation it gives sensitivity 0.87, specificity 0.81 and precision 0.84, and on our held-out test split sensitivity 0.87, specificity 0.81, precision 0.83, accuracy 0.84. Scaffold-grouped cross-validation, which better imitates a test set of different composition, gave lower numbers at 0.45 (sensitivity 0.84, specificity 0.69, precision 0.75, accuracy 0.77, measured before the final `max_features` tuning), so we expect real performance nearer those.

## Features

Each molecule is reduced to its largest fragment (salts removed) and turned into a fixed-length vector of 4,127 values, so SMILES of any length work (invalid or empty SMILES give a zero vector). The vector holds 2,048-bit Morgan ECFP4 fingerprints for scaffold diversity, plus 18 descriptors mapped to the known hERG pharmacophore: basic and tertiary nitrogen counts, Gasteiger partial charges and formal charge for the cation–π interaction with Tyr-652; logP, molecular weight, TPSA, Labute surface area and heavy-atom count for the lipophilicity and bulk that drive membrane crossing and cavity binding; aromatic ring count and aromatic atom fraction for π–π stacking; and rotatable bonds and fraction sp3 carbons for fit in the pore's inner cavity. We added 1,024-bit FCFP (atoms abstracted to roles such as donor, acceptor, aromatic, cation, so similar amines look alike across chemotypes), 1,024-bit atom-pair fingerprints, and a histogram of bond distances from each basic nitrogen to each aromatic atom, which encodes the pharmacophore geometry that plain Morgan bits cannot. The measured results back this: in 5-fold cross-validation the random-forest AUROC rose from 0.861 (Morgan only) to 0.890 (plus descriptors) to 0.908 (all blocks). With scaffold-grouped folds, where no scaffold appears on both sides, the values were 0.811, 0.844 and 0.860. In a drop-one-block test the descriptors mattered most (−0.011 AUROC when removed); removing the ECFP bits changed nothing (+0.001), so that block is redundant with the others, and the pharmacophore histogram alone added only about 0.002. We did not test ChemBERTa embeddings.

## Model and hyperparameters

The model is a scikit-learn **RandomForestClassifier** with 500 trees, `max_depth=20`, `min_samples_leaf=2`, `max_features=0.05`, `class_weight="balanced_subsample"` and seed 42; the exported ONNX file is 32 MB. We compared four models on every feature set with 5-fold cross-validated AUROC (mean ± std; random folds, on 8,000 training molecules). On the full feature set: random forest 0.908 ± 0.003, ExtraTrees 0.910 ± 0.004, HistGradientBoosting 0.905 ± 0.006 and logistic regression 0.853 ± 0.009. The three tree models are statistically indistinguishable; logistic regression is clearly worse, and its gap widens on new scaffolds (0.781 vs 0.860 for the forest). HistGradientBoosting could not be exported with the allowed skl2onnx version, so we chose the random forest. A small search under scaffold-grouped cross-validation showed `max_features=0.05` beat the default `sqrt` by about 0.006 AUROC (0.866 vs 0.860); the final test-split AUROC is 0.919. Five different random seeds changed scaffold-CV AUROC by under 0.001.
